# Référence visuelle initiale

La maquette `index.html` fournie est la référence de départ pour la future interface publique. Cette page documentaire relève ses choix visuels ; elle ne remplace pas la validation du design system.

## Palette et géométrie relevées

| Token | Valeur de référence |
| --- | --- |
| Rouge principal | `#ef4935` |
| Rouge foncé | `#d93625` |
| Encre | `#20201f` |
| Texte secondaire | `#77736f` |
| Fond crème | `#fff8f3` |
| Bordure | `#eee7e1` |
| Vert de confirmation | `#287a55` |
| Rayon de carte | `22px` |
| Largeur maximale | `1200px` |

La page utilise une police système proche d’Inter, des cartes arrondies, de légères ombres, des fonds crème et des accents rouges. Les points de rupture de la maquette sont autour de 950 px et 680 px ; elle réduit les animations quand `prefers-reduced-motion` est activé.

## Sections de la page d’accueil de référence

Bandeau et navigation, hero avec recherche, catégories, restaurants mis en avant, bannière culinaire, autres commerces, éléments de confiance, pied de page et navigation mobile.

Les visuels Unsplash, les noms d’établissements, les notes, les catégories et les interactions locales de la maquette sont des exemples. Ils ne doivent pas être présentés comme des données réelles ni être reliés à des paiements ou comptes réels.
